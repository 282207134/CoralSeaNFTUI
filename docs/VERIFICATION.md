# 开发与验证记录

验证日期：2026-10-20（Asia/Tokyo）。

## 环境

- Windows，Flutter 3.35.7，Dart 3.9.2，JDK 21。
- Android SDK / Android 35，x86_64 Android 模拟器 `flutter_emulator`。
- 模拟器启用宿主机 GPU；首次软件图形运行较慢，重启为硬件图形模式后端到端测试通过。
